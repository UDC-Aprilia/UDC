Gestione notizie e comunicati

Pubblica dalla scrivania o dal cellulare. Le modifiche appariranno sul sito quando GitHub Pages avrà aggiornato le pagine.

Accesso protetto alle modifiche, non pagina segreta. Solo chi possiede un token GitHub con autorizzazioni sul repository può pubblicare. Il token non viene memorizzato nel browser. Non inserirlo su dispositivi condivisi.

1. Collega GitHub

Usa un token fine-grained autorizzato esclusivamente per il repository del sito, con Contents: Read and write. Non pubblicare il token e revocalo se sospetti che sia stato copiato.

Gestisci token GitHub ↗

2. Cosa vuoi pubblicare?

Seleziona la sezione. Ogni contenuto è modificabile o rimovibile dall'archivio pubblico.

3. Nuovo articolo di stampa

Inserisci solo titoli e brevi descrizioni; il testo integrale resta sul sito della testata.

Non pubblicare come notizia una ricerca automatica non verificata. Cerca articoli su Google News ↗, verifica la fonte, poi inserisci il link.

Carica esclusivamente comunicati PDF definitivi, su carta intestata e approvati dal coordinamento. Verranno archiviati nella cartella documenti/ANNO/.

Per modificare titolo o descrizione di un documento esistente non serve caricare di nuovo il PDF. Se scegli un altro PDF verrà pubblicato un nuovo file; l'originale rimane nello storico GitHub.

Apri il modello di carta intestata stampabile ↗

4. Contenuti già pubblicati

Modifica o rimuovi le schede. La rimozione toglie la voce dal sito, non dalla cronologia GitHub.

Le modifiche vengono pubblicate nel repository GitHub configurato. Rassegna stampa · Attività · Archivio PDF · Gestione foto. Controlla diritti d'autore, autorizzazioni e dati personali prima di pubblicare.
