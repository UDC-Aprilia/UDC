Gestione notizie e comunicati

Pubblica dalla scrivania o dal cellulare. Le modifiche appariranno sul sito quando GitHub Pages avrà aggiornato le pagine.

Accesso protetto alle modifiche, non pagina segreta. Solo chi possiede un token GitHub con autorizzazioni sul repository può pubblicare. Il token non viene memorizzato nel browser. Non inserirlo su dispositivi condivisi.

1. Collega GitHub

Usa un token fine-grained autorizzato esclusivamente per il repository del sito, con Contents: Read and write . Non pubblicare il token e revocalo se sospetti che sia stato copiato.

Gestisci token GitHub ↗

2. Cosa vuoi pubblicare?

Seleziona la sezione. Ogni contenuto è modificabile o rimovibile dall'archivio pubblico.

3. Nuovo articolo di stampa

Inserisci solo titoli e brevi descrizioni; il testo integrale resta sul sito della testata.

Inserisci esclusivamente informazioni istituzionali autorizzate alla pubblicazione.

Fotografia istituzionale
Foto profilo

JPEG, PNG o WebP, massimo 5 MB. La fotografia sarà visualizzata in cornice rotonda. Se non scegli un nuovo file, la foto esistente resta invariata.

Non pubblicare come notizia una ricerca automatica non verificata. Cerca articoli su Google News ↗ , verifica la fonte, poi inserisci il link.

La nuova foto sostituisce quella indicata sopra. Sarà pubblica e resterà nella cronologia GitHub.

Carica esclusivamente copie PDF o DOCX autorizzate alla pubblicazione. Per le lettere ricevute conserva l’intestazione dell’ente mittente. Verranno archiviati nella cartella documenti/ANNO/ oppure lettere/ANNO/ .

Il documento pubblicato sarà accessibile e scaricabile da chiunque. Completa le verifiche nel riquadro sottostante.

Per modificare titolo o descrizione di un documento esistente non serve caricare di nuovo il file. Se scegli un altro file dello stesso formato verrà pubblicato un nuovo file; l'originale rimane nello storico GitHub.

Accedi alla modulistica riservata su GitHub ↗
Accesso consentito da GitHub solo agli utenti autorizzati. Scarica il modello HTML e aprilo localmente per compilare e stampare. Non caricare documenti riservati nel sito pubblico.

Verifica preventiva obbligatoria

Non caricare originali riservati. Anche i rami di prova sono pubblici. Verifica anche testi, immagini, firme, allegati e metadati.

Pubblicazione bloccata: verifica incompleta.

4. Contenuti già pubblicati

Modifica o rimuovi le schede. La rimozione toglie la voce dal sito, non dalla cronologia GitHub.

Le modifiche vengono pubblicate nel repository GitHub configurato. Rassegna stampa · Attività · Archivio documenti · Gestione foto . Controlla diritti d'autore, autorizzazioni e dati personali prima di pubblicare.
