Gestione editoriale

Pubblica le tue fotografie

Carica nuove immagini anche dal cellulare, modifica le didascalie e scegli quali foto mostrare nella galleria e nella Home.

Accesso protetto da GitHub. Questa pagina non conserva password o token: i comandi di pubblicazione funzionano solo con una credenziale GitHub autorizzata. L'indirizzo della pagina non è segreto.

1. Collegati al repository

Il token deve essere autorizzato solo per questo repository e avere il permesso Contents: Read and write. Non inserirlo in link, messaggi, file o schermate pubbliche. Rimane soltanto nella memoria di questa scheda e viene eliminato chiudendola.

Crea un token su GitHub ↗

2. Aggiungi fotografie

Seleziona fino a 10 immagini alla volta. Verranno ottimizzate per il web direttamente sul dispositivo.

3. Fotografie pubblicate

Modifica le didascalie o rimuovi foto dalla galleria. Le immagini rimosse restano nella cronologia GitHub.

Per vedere le modifiche online, attendi che GitHub Pages completi la pubblicazione. Apri la galleria ↗

Prima di pubblicare immagini di persone verifica di avere i diritti e le autorizzazioni necessarie.
