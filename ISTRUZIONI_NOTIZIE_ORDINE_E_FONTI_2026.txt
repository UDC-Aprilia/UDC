FONTI E AUTORESPONSABILITÀ
Configurazione in data/fonti-notizie.json. Il job .github/workflows/aggiorna-notizie.yml aggiorna data/web-news.json ogni 6 ore su GitHub Actions, da abilitare sul repository. Google News non garantisce disponibilità né restituisce sempre il link diretto. Alcuni risultati potrebbero essere vuoti. Nessun articolo completo, immagine o descrizione copiata viene acquisito.

La provenienza del Comune viene verificata anche tramite il dominio URL del tag source, non solo mediante l'etichetta testuale. Le notizie del Comune sono separate da quelle di partito. Le ricerche automatiche non equivalgono a un'approvazione editoriale: controllare periodicamente titoli, fonti, licenze, pertinanza e condizioni RSS. Escludere fonti non autorizzate; valutare con un legale le modalità di riuso ai sensi di L. 633/1941, art. 43-bis e altre norme applicabili. Nessuna soluzione tecnica può garantire assenza di contestazioni.

ISTRUZIONI
Estrarre lo ZIP. Per GitHub Pages caricare il CONTENUTO della cartella UDC-main nella radice del repository (non la cartella contenitore). In GitHub Actions eseguire manualmente il workflow Aggiorna notizie UDC Aprilia la prima volta. Verificare permessi di scrittura del workflow e il file data/web-news.json. In locale mediante file:// le richieste fetch possono essere bloccate dai browser; utilizzare un server HTTP locale, ad es. python -m http.server 8000, oppure la versione pubblicata.
